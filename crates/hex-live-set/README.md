# hex-live-set

## Purpose

Bounded control-side import of a finite, fixture-evidenced Live 12.4.6 Arrangement
subset into a fresh validated canonical project and resident media bank. Plain
UTF-8 XML/single-member gzip, exact original-document provenance and explicit
unsupported errors. See ../../docs/live-set-import.md for the field contract.

## Dependencies

hex-project for canonical snapshots/provenance, hex-media for bounded local WAV
validation, hex-engine for candidate compilation, pinned flate2/quick-xml/roxmltree
for bounded gzip/XML processing. hex-storage is a test-only save/reopen dependency.

## Does not own

Editable Ableton export, native UI/audio I/O, plugins, remote assets, project file
publication, a second project model, or full Live fidelity. Unknown original XML
is retained unchanged; no claim is made that it maps to editable Hex behavior.
Nonneutral pan requires explicit consent to Hex's unverified balance law.
