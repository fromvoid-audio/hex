# Private typed harmonic capture and lease proof (#2342 / PR158)

Starts from frozen6090a84076e7586525deb3459ae1ff0d1c161697. Everything added
is under `cfg(test)` in the isolated Operator test area. No production codec,
v9 state, provider trait, kernel, owned-pair interface, engine/render hook,
registry entry or pool is installed. The existing eight-word enable provider
and all admission limits remain unchanged. No reference control law is chosen.

The prototype captures neutral **already applied** f64 banks and builtin
weights at a checked boundary, retaining an independent real legacy enable
transition and law key. The receipt contains independent source/target
namespace-generation-context keys, both configuration identities, performance
boundary and clock generation. Control prepares contexts; a future host must
bind this receipt to its exclusive closed committed audio owner. The test model
does not prove a concurrent runtime export or a real host admission receipt.

## Evidence boundaries

The real legacy adapter dispatches pure builtin endpoints through the unchanged
provider sample route. Sine/saw/square/triangle fixtures include cap512; replacing
it with cap64 produces different table samples. The old enable trait still
rejects authored waveform changes. Private capture compatibility is a test-only
proposal for stable v8 base law with waveform/enable differences, not a widening
of that trait or a finalized harmonic contract.

Neutral f64 fixtures preserve signed-zero bits at exact endpoints, reject
nonfinite/overflowing coefficient arithmetic, and distinguish actual interrupted
source from canonical target or f32 requantization. The separate real enable
clock keeps its original start/duration and provider values; restarting it at
the harmonic boundary is a demonstrated negative control. No L1 normalization,
amplitude domain or f32 custom-output/aliasing acceptance follows from this proof.

17/25/64 compact note-binding fixtures preserve occurrence, gate, onset and
envelope law while detached copies remain independent of current edits. They
are binding/layout tests, not integrated engine first-paint admission or custom
PCM; the existing64 analytic /16 mutable distinction is untouched.

The preallocated lease-state model checks namespaces, generations, contexts,
configuration identities, clocks, closed transactions, recipe bytes, physical
slots, staging maps and reference overflow before mutation. It retains published
and detached records across refusal/abort/retry, rejects stale handles after
same-slot reuse and rejects old namespaces on recreated same-generation slots.
The tested refusal paths preserve exact sounding real legacy-provider PCM.
Retired slots and provider roots stay charged until explicit control reclamation;
drop instrumentation confirms providers survive current-owner removal while a
detached reference exists. Fingerprints compare coefficient/level bits exactly.

This does not prove real cross-kind history export/import, phase/feedback/LFO
transfer, callback allocation/deadlines, concurrent retirement fences, or native
painting/listening. Those require separately approved production contracts.

## Finite next alternatives; no forced fit

Keep installation blocked. First prove lossless reuse of existing level-clock
storage and keys, including absolute-to-relative clock conversion at interrupted
boundaries and detached roots, with complete recomputed charges. Independently
consider a genuinely shared legacy-enable binding representation, only with
actual lease-table/map/header charges and lifecycle proof. If neither fits,
return the measured refusal and seek an explicit contract decision; do not raise
caps, omit bindings, restart ramps, truncate builtin spectra or silently narrow
valid legacy behavior. The earlier harmonic-only aggregate proposal is not
implemented or authorized here.

Amplitude/Normalize/Repeat/range and builtin-to-User reference laws, full harmonic
painter/provider/runtime behavior and required native/user confirmation remain
incomplete. Blocked/draft HOLD remains; no passing gate receipt is registered.
