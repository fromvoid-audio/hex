# eq node wheel and option-q gestures

Pulse2801 / canonical PR407 extends the actual sparse-EQ ResponseGraph owner.
It depends temporarily on the same writer's PR406 graph/sidebar/default-analyzer
and corrected bundled-font fixture; it does not import other owners' features.
The merger combines qualified canonical sources and owns final full local CI.

Bare physical wheel-up over an existing low/high cut increases the existing
12/24/36/48db-per-octave slope choice; wheel-down decreases it. The parameter
wheel removes the platform's natural-scroll inversion once. High-resolution
input accumulates24px per step, clamps each input and stream work, and coalesces
one canonical typed Choice gesture. Trackpad Ended commits; ordinary mousewheel
uses one retained250ms quiet timer. Escape/blur/removal/disabled editing cancel.
At the slope limits, reversal applies immediately. Blank/bell/unsupported nodes
and modified wheel input retain their existing routing. Consumed cut input does
not scroll the outer device chain. Fractional input creates no history by itself.

Option pressed at bell-node drag start selects Q as the existing paired
frequency/Q parameter target. Q changes exponentially from the pressed node's
initial Q and relative vertical displacement, avoiding an absolute gain-to-Q
jump. Frequency, gain and stable node identity remain unchanged. Ordinary
frequency/gain dragging and existing cut/notch vertical-Q behavior remain.
Shift precision, pointer release, cancel, text focus, existing audition,
automation, Backspace and creation behavior retain their original owners.
There was no prior node-wheel binding or conflicting Option owner in this path.
No new DSP/filter law, backend, model or persistence format is introduced.

The view captures each worker GestureKey and stable parameter target. Wheel
streams also have a monotonically increasing graph-local stream identifier;
a previous stream's delayed terminal cannot finish/rebind a later same-node
worker key. Pending UI values are written only after accepted client requests.
Refused Begin cannot reuse an older drag plan or cancel another canonical key.
The shared graph API is opt-in with an empty default node list and bounds of64
existing IDs; other graph owners receive no wheel handler behavior by default.
