# exact native streamed readiness

PR237 / Pulse2542 extends the opted-in constructor publication path from PR236.
It adapts pure demand and protected extent mechanics from published PR177 source
`8d444c06c295e52a8aa0dde275a89ecec6f454e2`; current owner/Root/domain claims supply
actual custody. Historical component checkpoints in
[audio candidate publication](audio-candidate-publication.md) remain provenance.
This document describes the integrated initial/replacement path.

## one owner, one endpoint, exact transaction

A channel opts in before its first accepted domain or graph. Its existing finite
publication reservation gains a caller-selected exact-demand capacity per domain
and runtime cell. The same two Vec backings follow the actual runtime State and
return to its original slot before metadata destruction or report reuse. Checked
requested bytes, actual capacities and temporary construction overlap remain in
the caller retained/construction DATA limits. The actual State payload, domain
Vec capacity and dedicated demand backing also reduce the existing 32 MiB owned
runtime allowance before seal/split; subsequent real Utility transfers retain
that allowance. Immutable prepared graphs and the separate 32 MiB pool PCM scope
keep their existing exclusions. No aggregate cap or scalar completeness escape
is introduced. Public `require_complete` continues to refuse unresolved scalar
storage; native eligibility retains PR236's distinct scoped DATA and bounded
opaque RESOURCE custody contract, without RSS or OS-byte claims.

The Root retains each actual domain's control/catalog/disposal owner. Its single
move-only page loan travels through the real publication ring to one of the two
fixed callback domain slots. All generations borrow that endpoint; no producer is
cloned. Six reserved role Vecs and their catalog handles remain charged. A
borrowed promotion token exclusively holds the exact acknowledged role; all
involved domains are prevalidated before a musical/owner commit, followed only
by nonfallible role swaps. Dropping an unused token changes no protection.

The engine generates the next exact chunk or previews handoff from the current
actual predecessor. The stamp copies the actual prepared owner's canonical
Session source context, artifact identity, Root/device epoch, rate, command
prefix, predecessor and window. Catalog generation remains distinct from document
generation. Caller numbers cannot relabel that owner. A receipt must match its
actual domain incarnation and exact extents, including valid short-page length.
Decoded or merely queued buffers do not establish readiness.

The callback alone pumps bounded completions and requests pages. It first binds
all exact protected extents, then calls the existing engine transaction for that
chunk. On success it commits role protection and proceeds to the next chunk.
Missing pages or readiness capacity refusal zero only the uncommitted remainder,
report BUFFERING with committed frame count, and preserve earlier PCM and clock
commits. No whole-Session copy or rollback is used. Genuine action/kernel faults
remain errors with already-committed outcome metadata recorded first. The normal
and post-node observer facades share this path; observer offsets include earlier
committed chunks. The current eligible Utility class does not admit EQ8 spectrum
targets. Independent sample preview retains its existing behavior.

Candidate preview runs before installation at render's actual output length.
Actual grouped ownership preflight still may Retry; pure preview is no guarantee
of transfer capacity. Retry invalidates speculative Candidate protection before
servicing the old active window, preserving Active ownership and applied revision.
A bounded drain consumes actual worker failure receipts, releases their pending
request keys and retains the last exact failure in charged domain metadata.
A failure affecting the requested window reports refusal; later service may retry.
This avoids stranding old active audio after a real pool-capacity failure.

## transport and acknowledgement

The opt-in path intercepts at most the existing 32 queued commands before preview.
Only an unapplied Play is deferred scalar intent. Every Pause executes the real
zero-page action, including metronome reset, and cancels pending Play/readiness.
Pause before any runtime remains valid. Priority Stop uses the independent marker,
resets the actual predecessor immediately and invalidates obsolete intents. A
later Play waits at that reset position. Seek, PlayFrom, launch and route-changing
actions are explicitly rejected here; their streamed preparation is PR238.

Dequeued-command telemetry is distinct from the resolved/applied streamed prefix.
Pending Play and an empty output slice cannot authorize an install ACK. Paused
zero-page installation is valid when no pending Play needs a ready chunk. Ready
installation repeats actual predecessor/group preflight and preserves the existing
return-capacity, cancellation, claims and route publication barriers. Status
BUFFERING/refusal/frame counters are observations, never readiness authority.

## lifetime, evidence and remaining work

Cancel, stale association, pressure and permanent refusal preserve actual runtime,
anchor, catalog and source-bank identity. Existing terminal custody returns loans
only after both callback guards and completed stream-handle extraction; normal
carrier/endpoint metadata destruction, worker join and complete pool conservation
precede READY. Charges and domain occupancy remain through report consumption.
No callback lock, join, allocation, Arc clone or final owner Drop is introduced.
Zero total and signed-net allocation/deallocation probes cover the exercised
native queue/render/transport and protected-promotion paths; clone absence and
lock/Drop placement are source-inspection evidence, not universal instrumentation.

Focused controls use real verified WAV workers and the actual native owner,
publication rings and lifetime gates: first Play waits without clock/ACK progress;
wrong document context returns the same original owner/domain Vec; partial chunks
retain PCM and clocks; a two-source cache refusal preserves the applied prefix;
Pause/Stop pass blocked Play; and a ready replacement's real Utility transfer
Retry permits the old runtime's next page and exact candidate cancellation. Stream
controls retain wrong/stale stamps, unread receipt pressure, short-page refusal,
exact pair return and pool accounting. The cap control exercises exact 32 MiB,
one-byte excess and overflow without changing original-bank recovery.

Legacy resident publication and borrowed-page miss-silence/clock-progress behavior
remain unchanged. This source path does not wire Session worker snapshots into
native UI publication (PR239), complete streamed seek/launch (PR238), lift import
limits, establish 100-track native deadlines, or certify OS Dispose success.
Original #24/#177 broad acceptance and native listening/UI checks remain open.
