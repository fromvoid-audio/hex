# iteration 2 state views

Five full-resolution views use the r67 theme and unchanged compact geometry.
Open index.html through the design server to compare them; click a view for its
full-size PNG. The portable Frame project in the parent folder includes matching
editable states. These are concept states, with simulated playback meters.

- default.png: arrangement stopped; inactive meters.
- playing.png: arrangement playing; cyan/orange/red levels and pause control.
- session.png: session stopped; inactive meters.
- session-playing.png: session playing; active meters and session transport.
- clip-colors.png: custom color picker open over stopped session.
