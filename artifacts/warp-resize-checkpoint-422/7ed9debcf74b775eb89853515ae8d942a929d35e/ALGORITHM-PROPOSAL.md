## Concrete correct search structure (proposal, not implemented)
Use a directed PREFIX-CERTIFICATION search from f0, independently in both directions, within the existing maximum prepared domain of2^24frames. A node represents a closed INTEGER command-frame interval. It may be skipped ONLY when an exact conservative certificate proves ALL endpoints inside that interval satisfy P. Otherwise split it, visit the half nearest f0 FIRST, and descend to singleton if necessary. At a singleton evaluate the actual existing model plus canonical metadata admission. The first invalid singleton terminates that direction; the immediately preceding valid frame is the inclusive bound. If a previously certified whole prefix was skipped, that certificate proves no illegal island was crossed. Final bounds and the one adjacent outside frame must be revalidated by actual canonical P. This is NOT binary search on a presumed monotonic predicate; it is ordered interval refinement with sound all-valid certificates.

The certificate must be backed by actual retime/map/tempo structure, not duration ratio or sampled point agreement:
- Capture original retained root, view interval, warp phase/cycles, marker source positions/beats and original projection origin; retain exact model scale rounding (u128 numerator + denominator/2), frame↔beat conversion, signed virtual root prefix and Q32 source interpolation.
- Partition/refine at POSSIBLE crossings between scaled root/view/phase-cycle marker boundaries and project tempo points. Within a fixed overlap topology, bound every actual prepared segment's output-frame and source-Q32 differences with outward integer rounding. Reject a certificate if topology, positivity/sub-frame validity, source bounds, mode/pitch range or any intermediate checked operation is uncertain.
- The existing validator alone decides individual candidates. A private certificate may only conservatively decline to certify; it cannot establish validity from a second approximate admission law. Bounds for a certified interval must place EVERY compensated segment ratio within the unchanged epsilon-inclusive range (and all map/model constraints).
- Rounding uncertainty must trigger further refinement down to actual neighboring INTEGER frames, never a guessed ±1 radius/coarse grid. Root's requested nearest representable inclusive boundary follows from the ordered prefix invariant even with nonuniform markers/tempo and disconnected far legal islands.
